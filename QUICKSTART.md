# Quick Start Guide

## Installation (2 minutes)

```bash
conda create -n lung_ct python=3.8
conda activate lung_ct
pip install -r requirements.txt
```

## Test Models

```bash
python src/models/unet3d.py
python src/models/vnet.py  
python src/pathplanning/astar.py
```
