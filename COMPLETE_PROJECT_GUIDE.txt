## 🎯 Usage Examples

### Training

```bash
# Train airway segmentation model
python scripts/train_airway.py \
    --config configs/airway_unet_config.yaml \
    --data_dir ./data/processed \
    --output_dir ./experiments/airway \
    --gpu 0
```

**Features:**
- Mixed precision (FP16) for faster training
- Gradient accumulation for large batches
- TensorBoard logging (view with `tensorboard --logdir experiments/airway/logs`)
- Automatic checkpoint saving (best + periodic)
- Validation metrics computed every epoch
- Learning rate scheduling

### Inference

```bash
# Run complete pipeline on new CT scan
python scripts/inference.py \
    --input ./data/test/patient_001.nii.gz \
    --airway_model ./weights/airway_unet_best.pth \
    --nodule_model ./weights/nodule_vnet_best.pth \
    --output_dir ./results/patient_001
```

**Output files:**
```
results/patient_001/
├── airway_segmentation.nii.gz    # Binary airway mask
├── nodules.json                  # Nodule locations & metadata
├── navigation_paths.json         # Path planning results
├── metadata.json                 # Processing metadata
└── visualization.png             # (if visualization added)
```
